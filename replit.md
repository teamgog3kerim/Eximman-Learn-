# Run the Academy on Replit

This project is a Vite, React, and TypeScript browser demo.

- The Replit preview runs with `npm run dev` on port 5000.
- Run `npm run lint` for the TypeScript check.
- Run `npm run build` to create the production build in `dist/`.

## Important limits of this demo

- Learner identities, progress, quiz results, and theme preferences are stored in the current browser only. They are not backed up or shared between devices.
- The demo identity switch and admin view are not secure authentication or access control.
- Registration, payment collection, and payment verification are not connected. Do not send money or payment receipts based on this demo.
- Certificates are local course-progress records, not accredited or independently verifiable credentials.
- Resource downloads are generated sample text summaries, not original PDF, Excel, or Word source files. Regulatory, customs, banking, export, and tax material has not been verified against current official sources. Check relevant authorities before relying on it.
- Calculator outputs are educational estimates, not financial, tax, or legal advice.

Do not accept real student records, payments, or official-document claims until appropriate secure services, payment providers, authoritative content sources, and operational review have been added.
