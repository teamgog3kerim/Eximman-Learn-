Keep the existing curriculum courses, quizzes, progress features, cost calculators, and certifications in the app when updating the overview, accounts, or subscriptions.

**Why:** The user explicitly asked to retain these features while improving the app.

**How to apply:** Add account, payment, and admin functionality around the existing learning tools; do not replace or remove the course content.

Carry the approved public landing-page visual language into authenticated learning screens: warm parchment backgrounds, forest-green structure, and restrained ochre accents.

**Why:** The user praised the landing-page organization and theme, then asked for the remaining learning screens to use a polished, consistent design.

**How to apply:** Keep courses, quizzes, progress, certificates, and calculators visually consistent with the public page while preserving their existing behavior and calculations.
